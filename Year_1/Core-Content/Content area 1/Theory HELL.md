Presence detection : checks for user input

Length check : Checks the length of the inputted statement 

Type Check: Checking to see if the correct type of data has been entered #

Format check : Rejects the input to see if it has been entered in the correct format      (For example Dates “DD/MM/YY = GB” “MM/DD/YY = USA”)

Range check: Checks that the data is between a certain range of numbers 

Constraint check: sees if any restraints have been put onto the input (i.e. passwords needing special characters)

Testing methods

Concept testing: testing something before a product is made so you don’t waste Time coding a whole app to see if it will work

Unit testing: Testing individual functions or modules work

Boundary testing:  3 types of test 1. Normal value 2. Extreme value – At the boundaries  3.erroneous (Above the boundary should error)

Integration Testing: Making sure all functions and models work together in the final product

System test: Making sure the entire system Works

Performance/load/stress testing: testing to see how the application runs and if it fails at lower RAM like 2GB – 6GB – Multi system testing and Testing to see how it runs with background applications running

Acceptance and Usability Testing: Testing that the system works in a practical environment

Regression testing: When new features or bugs are added/ fixed you check to make sure no existing features break

Root cause analysis
Finding the actual Issue and properly fixing it Rather than using a Quick fix to repair it
