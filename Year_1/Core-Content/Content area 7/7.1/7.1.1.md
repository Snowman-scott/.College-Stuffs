CPU – the CPU is the brain of the computer, it runs all the calculation for you
RAM – Holds information that needs to be passed to the CPU Via buses – it does not retain information once the power is lost
Storage – Holds your data like photos and apps so you can use them every time you boot up your Pc 
Motherboard – allows everything to connect to each other and talk to each other
Power supply – Provides power to everything on the motherboard
GPU – Like a second CPU but only for graphical calculations and processing
Io – For plugging in a mouse and keyboard and other peripherals like monitors and audio
