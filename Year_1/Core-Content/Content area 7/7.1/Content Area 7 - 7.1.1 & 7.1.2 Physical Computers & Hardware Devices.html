Servers and Workstations

🗄️ Servers

Powerful computers designed to provide services, resources, and data to other computers (clients) over a network.

Key Features:

  • High reliability: Built for 24/7 operation with redundant components
  • Multiple processors: Can handle many simultaneous requests
  • Large RAM capacity: 64GB to 1TB+ for handling multiple users
  • Rack-mountable: Designed to fit in server racks for data centers
  • Remote management: Can be managed without physical access

Common Types:

  • Web servers: Host websites and web applications
  • File servers: Store and share files across a network
  • Database servers: Manage and serve database queries
  • Email servers: Handle sending, receiving, and storing emails

🎨 Workstations

High-end computers optimized for professional, technical, or scientific applications requiring significant computational power.

Key Features:

  • Professional-grade GPUs: NVIDIA Quadro/RTX, AMD Radeon Pro for rendering
  • ECC memory: Error-correcting RAM for mission-critical accuracy
  • Multi-core processors: Intel Xeon or AMD Threadripper
  • Large storage: Fast NVMe SSDs for handling large files

Common Uses:

  • CAD/CAM: Engineering design, architecture, product development
  • 3D modeling: Animation, visual effects, game development
  • Video editing: 4K/8K video production and color grading
  • Scientific computing: Data analysis, simulations, research

Embedded Systems

What Are Embedded Systems?

Specialized computer systems designed to perform dedicated functions within larger mechanical or electrical systems. Unlike general-purpose computers, they are optimized for specific tasks.

Characteristics

  • Task-specific: Designed for a single purpose or limited set of functions
  • Real-time operation: Must respond to inputs within strict time constraints
  • Resource-constrained: Limited processing power, memory, and storage
  • Low power consumption: Often battery-powered or energy-efficient
  • Reliability: Must operate continuously without failure
  • Cost-effective: Optimized for mass production at low cost

Common Examples

🚗 Automotive

Engine control units, ABS systems, entertainment systems, parking sensors

🏠 Home Appliances

Washing machines, microwaves, thermostats, smart TVs, security systems

📱 Consumer Electronics

Digital cameras, fitness trackers, smartwatches, gaming consoles

🏭 Industrial

Manufacturing robots, PLCs, sensors, control systems

🏥 Medical

Pacemakers, MRI machines, patient monitors, infusion pumps

🛩️ Aerospace

Flight control systems, navigation, autopilot

Hardware Device Categories

⌨️

Input Devices

Hardware that allows users to enter data and commands into a computer

Examples: Keyboard, mouse, scanner, microphone, webcam, touchscreen

🖥️

Output Devices

Hardware that presents data from the computer to the user

Examples: Monitor, printer, speakers, headphones, projector

💾

Storage Devices

Hardware that stores data permanently or temporarily

Examples: HDD, SSD, USB drive, SD card, optical disc

🔧

Processing Components

Hardware that processes data and executes instructions

Examples: CPU, GPU, RAM, motherboard

Understanding I/O Devices

Some devices can be both input AND output (I/O devices). Examples include:

  • Touchscreens: Display information (output) and receive touch input
  • Network cards: Send and receive data over networks
  • Storage devices: Read (input) and write (output) data
  • USB drives: Transfer data in both directions

Key Processing Components

🧠 CPU (Central Processing Unit)

The "brain" of the computer that executes instructions and performs calculations.

  • Cores: Independent processing units (dual-core, quad-core, etc.)
  • Clock speed: Measured in GHz - how fast it processes instructions
  • Cache: Small, fast memory for frequently accessed data
  • Examples: Intel Core i5/i7/i9, AMD Ryzen 5/7/9

🎮 GPU (Graphics Processing Unit)

Specialized processor designed for rendering graphics and parallel processing tasks.

  • Integrated: Built into CPU, shares system RAM (Intel UHD, AMD Radeon)
  • Dedicated: Separate card with own memory (NVIDIA GeForce, AMD Radeon)
  • Professional: For workstations (NVIDIA Quadro/RTX, AMD Pro)
  • Uses: Gaming, video editing, 3D rendering, AI/machine learning

💾 RAM (Random Access Memory)

Temporary, fast storage that holds data and programs currently in use.

  • Volatile: Data is lost when power is turned off
  • Capacity: Typically 8GB-64GB for consumer systems
  • Speed: DDR4 (2400-3200MHz), DDR5 (4800-6400MHz)
  • More RAM: Allows running more programs simultaneously

🔌 Motherboard

Main circuit board that connects all components together.

  • Chipset: Controls communication between components
  • Expansion slots: PCIe for GPUs, sound cards, network cards
  • Ports: USB, audio, video, network connections
  • Form factors: ATX, Micro-ATX, Mini-ITX (different sizes)

Storage Type Speed Capacity Cost Best Use
HDD (Hard Disk Drive) Slow (80-160 MB/s) 1TB - 20TB $$$ Mass storage, archives, backups

💡 Key Differences

  • HDD: Uses spinning magnetic platters - mechanical, slower, cheaper per GB, good for bulk storage
  • SSD: Uses flash memory chips - no moving parts, much faster, more expensive, better for performance
  • NVMe: Connects directly to PCIe - fastest storage available, essential for high-end systems

Exam Question 5

Question 5 – 9 marks – Analyse

A video editing company is experiencing slow performance when editing 4K video footage. Their current computers have Intel Core i5 processors (4 cores), 8GB RAM, integrated graphics, and 1TB HDDs. Editors report that:

  • Loading project files takes 2-3 minutes
  • Playback stutters when previewing edits
  • Rendering final videos takes over 8 hours for a 10-minute clip
  • The software frequently shows "out of memory" warnings

Analyse how each hardware component (CPU, RAM, GPU, and storage) contributes to these performance issues. In your answer, explain how upgrading each component would address specific problems and how these components interact to affect overall performance.

Command word: Analyse

Break down information to examine its parts, identify relationships, and draw conclusions. Show detailed understanding of how factors interact and impact the scenario.

Slide 16 / 24

Model Answer: Question 5 (9 marks) - Part 1

Storage (HDD) Analysis

The HDD is causing slow file loading times (2-3 minutes) because traditional hard drives have read speeds of only 80-160 MB/s (1 mark). 4K video files are extremely large (often 100GB+), so loading them from slow storage creates a bottleneck (1 mark). Upgrading to an NVMe SSD (3000-7000 MB/s) would reduce loading times by 20-40x, bringing load times down to seconds rather than minutes (1 mark).

RAM Analysis

The "out of memory" warnings indicate insufficient RAM (1 mark). 8GB is inadequate for 4K video editing, as active footage, preview renders, and the editing software itself must all fit in RAM simultaneously (1 mark). When RAM fills up, the system uses virtual memory on the slow HDD, causing severe performance degradation and stuttering playback (1 mark). Upgrading to 32GB or 64GB RAM would allow the entire working project to stay in fast memory, eliminating virtual memory usage and enabling smooth playback (1 mark).

Slide 17 / 24

Model Answer: Question 5 (9 marks) - Part 2

GPU Analysis

Integrated graphics lack dedicated video memory and processing power for 4K video effects (1 mark). This causes stuttering during playback preview as the GPU cannot decode and display 4K footage in real-time (1 mark). A dedicated professional GPU (e.g., NVIDIA RTX) would provide hardware-accelerated video encoding/decoding, dramatically improving preview performance and reducing render times through GPU-accelerated effects processing (1 mark).

CPU Analysis & Component Interaction

The 4-core i5 processor is the bottleneck for 8-hour render times (1 mark). Video rendering is heavily CPU-dependent, and more cores allow parallel processing of multiple video frames simultaneously (1 mark). Upgrading to a multi-core processor (8-16 cores) would reduce render times proportionally.

Component Interaction: All four components work together in the video editing pipeline - storage provides data to RAM, RAM feeds the CPU/GPU for processing, and results are written back (1 mark). The slowest component creates a bottleneck that limits overall performance, which is why all four upgrades would be beneficial for optimal performance (1 mark).

Note: Full marks require explaining each component's contribution, the interaction between components, and how upgrades address specific problems.

Question 6 – 12 marks – Evaluate

A growing e-commerce company with 50 employees needs to upgrade their IT infrastructure. Currently, they use a mix of aging desktop computers and personal laptops. The company faces the following requirements:

  • Customer service team (20 staff) - need reliable systems for order processing, email, and web browsing
  • Web development team (10 staff) - need powerful systems for coding, testing, and running multiple virtual machines
  • Management team (5 staff) - frequently travel to meetings and need mobile access to company systems
  • Warehouse staff (15 staff) - need basic systems for inventory management on handheld devices

The company must also implement a centralized file storage and database system to replace their current solution of files stored on individual computers.

Evaluate the most appropriate combination of computer types (desktops, laptops, workstations, servers, mobile devices) for this company. Justify your recommendations with evidence, considering factors such as cost-effectiveness, performance requirements, scalability, and business continuity.

Command word: Evaluate

Make a reasoned judgement after considering the advantages and disadvantages of different options, supported by evidence or examples.

Slide 19 / 24

Model Answer: Question 6 (12 marks) - Part 1

Recommended Infrastructure

Customer Service Team (20 staff) - Desktop Computers: Standard desktop computers provide sufficient performance for order processing and web applications at the lowest cost per unit (approximately £600-800 each compared to £1000+ for equivalent laptops) (1 mark). Since these staff work exclusively in the office, mobility is not required, and desktops offer better ergonomics with larger monitors and separate keyboards, improving productivity for data-entry tasks (1 mark). Desktops are also easier and cheaper to repair/upgrade, reducing long-term IT costs (1 mark).

Web Development Team

Web Development Team (10 staff) - Professional Workstations: Running multiple virtual machines and development environments requires high-performance CPUs (8+ cores) and 32-64GB RAM, which workstations provide cost-effectively (1 mark). Workstations offer superior performance and upgradeability compared to laptops, allowing the company to extend hardware lifespan by upgrading components as needs grow (1 mark). The ability to add multiple monitors and high-speed storage makes workstations ideal for developer productivity (1 mark).

Management Team

Management Team (5 staff) - Business Laptops: Frequent travel necessitates portable systems (1 mark). Business-class laptops (£1000-1500) provide adequate performance for management tasks while offering mobility and longer battery life than consumer models (1 mark). While more expensive per unit, the small quantity (5 units) minimizes overall cost impact (1 mark).

Model Answer: Question 6 (12 marks) - Part 2

Warehouse Staff & Server Infrastructure

Warehouse Staff (15 staff) - Mobile Devices/Tablets: Handheld devices or tablets with barcode scanners provide mobility within the warehouse for real-time inventory updates (1 mark). These are cost-effective (£300-500 per unit) and purpose-built for warehouse management applications (1 mark).

Centralized Server Infrastructure - Dedicated Server: A server is essential for centralized file storage and database management, replacing the current insecure practice of storing files on individual computers (1 mark). Server benefits include: automated backup capabilities ensuring business continuity, simultaneous access for all 50 employees, and 24/7 reliability with redundant components (RAID storage, redundant power supplies) minimizing downtime risk (1 mark).

Cost-Benefit Analysis & Scalability

Total Estimated Investment:

  • 20 × Desktops @ £700 = £14,000
  • 10 × Workstations @ £2000 = £20,000
  • 5 × Laptops @ £1200 = £6,000
  • 15 × Tablets @ £400 = £6,000
  • 1 × Server @ £5,000 = £5,000

This tiered approach optimizes budget allocation by matching system cost to performance requirements rather than buying uniform high-spec systems for all staff (1 mark). The infrastructure is scalable - as the company grows, they can add more desktops for customer service, upgrade server storage capacity, or add workstations for developers without replacing the entire system (1 mark).

How Hardware Components Work Together

The Computer System Flow

All hardware components work together in a coordinated system to process data and produce results.

Input → Process → Output → Storage

⌨️
INPUT
Data enters via keyboard, mouse, webcam, etc.
🧠
PROCESS
CPU and RAM process the data
🖥️
OUTPUT
Results shown on monitor, speakers, printer
💾
STORAGE
Data saved to SSD/HDD for later use

Example: Writing a Document

  • Input: You type text using the keyboard
  • Process: CPU processes keystrokes, RAM holds document in memory
  • Output: Monitor displays the text as you type
  • Storage: Document saved to SSD when you click "Save"

Example: Playing a Video Game

  • Input: Mouse/controller sends player commands
  • Process: CPU calculates game logic, GPU renders graphics, RAM holds game data
  • Output: Monitor displays graphics, speakers play audio
  • Storage: Game progress saved to SSD, game files loaded from storage

Module Summary

Physical Computers (7.1.1)

  • Desktop: Stationary, powerful, upgradable, cost-effective
  • Laptop: Portable, all-in-one, battery-powered, convenient
  • Server: 24/7 operation, serves multiple clients, high reliability
  • Workstation: Professional-grade for CAD, rendering, video editing
  • Embedded: Specialized, task-specific, integrated into other systems

Hardware Devices (7.1.2)

  • Input devices: Keyboard, mouse, webcam, microphone, scanner - get data INTO computer
  • Output devices: Monitor, printer, speakers, headphones - present data TO user
  • Storage devices: HDD (slow, cheap), SSD (fast, expensive), NVMe (fastest) - permanent data storage
  • Processing components: CPU (brain), GPU (graphics), RAM (temporary memory), Motherboard (connects all)
  • I/O devices: Touchscreen, network card, USB drive - both input AND output
  • System flow: Input → Process (CPU/RAM) → Output → Storage

Key Takeaway

Understanding different computer types and hardware components helps you choose the right system for specific tasks and understand how all parts work together to process data effectively.
