4. Switching to AWS has its benefits and its issues.

Moving to Cloud computing can allow you to have more flexibility and scalability in the future, allowing for better upscaling if needed later on.
This can also cut costs as it does not cost a lot to get set up with CSPs, and you can pay more if you need more resources later on down the road.

The issues with migrating to AWS are:

Getting all the current data onto the AWS Cloud network could take time and risk of data being lost along the way.
If the network or data centres go down, you cannot use your services. If you have no internet, you won't be able to use your CSP, but with the dedicated on-site server, you will be able to.

5.  A Hybrid model would work the best for this company.

Seeing as they have sensitive customer data, they cannot switch to a fully public cloud deployment as that increases the chances of a data breach.
A data breach can cost the company a lot of money in fines for breaking the Data Protection Act.
A hybrid deployment would allow for all customer data to be kept securely on dedicated machines, but allows all the front-end, like the website and anything else non-sensitive, to be run on a public cloud deployment like AWS.
This gives the flexibility and scalability of Cloud computing with AWS and Azure, with the security for data.

The disadvantage of Hybrid is a higher cost, but this will outweigh any fines incurred by breaching the Data Protection Act.

In conclusion, I recommend opting for the hybrid solution to ensure all customer data remains secure.
