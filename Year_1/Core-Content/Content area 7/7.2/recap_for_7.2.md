# Question 6
Version controll
One feature is Rolling back code, You commit a copy of your code at a point in time, If you break the code while developing after that commit you can use the commit to move your files and code back to the old version, where it fully worked.
Another feature of version controll is collaboration. You can have multiple people work on a specific part of a project at a time, commiting to different branches in a repo, they can then combine or merge all the branches together making the application work while speeding up production as more than one person can work on the code at a time.
Another feature of version controll is a changelog. Whenever you edit a file, and commit a new copy of that file it will show how many lines you changed, how many you deleted and what exactly chaged, this helps to see what got removed, added and changed. this gives your file a compleate history of all the changes to it over time

There are also some other features like Forking, Issue tracking and project managment(github), Code review /  Pull requests and finally backups & remote storage.
