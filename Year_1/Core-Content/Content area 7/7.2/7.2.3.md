# Code development tools

## Question 1
### State two features of code editing tools found in integrated development environments (IDEs)
1. Syntax highlighting, If the code written has an error, and the IDE has an interpretor selected for a language it will show a line to highlight where the errors and bugs are in the code.
2. IntelliSense, This feature provides suggestions for code completion, error checking, and documentation as you type.
