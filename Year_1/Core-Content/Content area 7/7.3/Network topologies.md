5.	A mesh network would be suitable for a hospital especially if they need high reliability. 

A mesh network would give high reliability as every computer in the hospital would be connected together. This will mean that even if 2 or 3 cables went down you will still have a rout to get data to the server storing all the data you need. This means that the network has a high reliability as all the extra paths are for fault tolerancing, this means that the network will always be up and only go down for maintenance or if a switch/ key component fails.

A mesh network also has really good performance, this is due to the fact that all the computers are connected together. If a large amount of data needs to be sent across the network, it can use multiple cables to send it faster as that will allow it to use more bandwidth and travel across the network at a faster rate speeding up the task the person is doing.

The downside to a Mesh network is the cost. A mesh network will cost more than normal networking, this is due to all the money that needs to be spent on cables, switches, and putting in the infrastructure. 6.	Extended star and wireless Topologies both have their strengths and weaknesses in a college environment. 

The advantages of an Extended star topology are:
Reliable: The whole system works together and if one branch goes out the other branches will stay online meaning that if one building was down the rest wouldn’t. It also would have a Lower latency connection and can have a faster speed compared to other topologies,

Security: The security of an Extended star topology is better than a wireless topology. This is because the hacker would have to be in a room with access to an Ethernet port to connect their machine to the network, this raises security as the person would probably be caught before making it into a server room or computer room

The Disadvantages of an Extended star topology are:
Cost: Extended star network use multiple switches going into a more powerful central switch, this means that you need one powerful switch, more lower power switches for buildings, then even more lower power switches for classrooms or running an access port to a room

Maintenance and Upkeep: Maintaining the server rooms and all the equipment will be an issue as there will be so many links to different buildings and different rooms. Unless everything is managed properly the maintenance will become a nightmare, especially trying to diagnose what cable has broken on what switch.
