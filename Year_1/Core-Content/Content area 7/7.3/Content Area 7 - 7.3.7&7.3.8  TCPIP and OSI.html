OSI MODEL

Open Systems Interconnection

Network Communication Framework

A conceptual model to understand how networks operate and standardise communication across 7 layers

The 7 Layers Overview

📚 OSI Model Structure

Each layer has specific functions and communicates with layers above and below it.

  • Layer 7 - Application: User-facing applications (HTTP, FTP, SMTP)
  • Layer 6 - Presentation: Data formatting, encryption, compression
  • Layer 5 - Session: Connection management between devices
  • Layer 4 - Transport: Reliable data transfer (TCP/UDP)
  • Layer 3 - Network: Routing and logical addressing (IP)
  • Layer 2 - Data Link: Physical addressing (MAC), frames
  • Layer 1 - Physical: Raw bit transmission

💡 Mnemonic: "All People Seem To Need Data Processing"

Layer 7 - Application

🌐 User-Facing Layer

Facilitates communication between end-user applications and the network. Provides network services like web browsing, email, and file transfer.

Common Protocols & Services:

📧 Email

POP3, SMTP

🌍 Web

HTTP/HTTPS, DNS

📁 Files

FTP, P2P

Examples You Use Daily

Web browsers • Email clients • Instagram • YouTube • Online games • Network drives

Layer 6 - Presentation

🔧 Data Configuration

This layer configures the data so the receiving device can understand it!

Key Functions:

  • Compression: Reduces data size for efficient transmission
  • Encryption & Decryption: Secures data during transmission
  • Translation: Converts data formats between different systems

Security Protocols:

🔒 SSL

Secure Socket Layer (deprecated/legacy)

🔐 TLS

Transport Layer Security (current standard)

4 / 18

Layer 5 - Session

🔗 Connection Management

Responsible for establishing and terminating connections between devices

Key Responsibilities:

  • Setting up: Establishes session connections
  • Managing: Controls connections between computers/devices
  • Dismantling: Terminates sessions when complete
  • Authenticating: Verifies user identity
  • Authorising: Grants appropriate permissions

💡 Think of it like a phone call

Dial and connect → Have conversation → Hang up and disconnect

5 / 18

Layer 4 - Transport

🚚 Reliable Data Transfer

Responsible for the reliable transfer of data between end systems

Key Functions:

  • End-to-End Communication: Between source and destination hosts
  • Segmentation: Breaks data into smaller segments
  • Reassembly: Reconstructs original data at destination

Key Protocols:

TCP

✓ Reliable - Guarantees delivery

✓ Connection-oriented

✓ Ordered delivery

Use: Web, email, file transfer

UDP

⚡ Fast - No connection overhead

⚡ Connectionless

⚡ No guarantee

Use: Streaming, gaming, VoIP

6 / 18

Layer 3 - Network

🗺️ Routing & Addressing

Handles data routing, packet forwarding, and logical addressing. Divides data into packets.

Key Functions:

  • Routing: Determines optimal path across multiple networks
  • Logical Addressing: Uses IP addresses to identify devices
  • Packet Forwarding: Transfers packets between networks
  • Fragmentation: Divides packets to fit network MTU
  • Quality of Service (QoS): Prioritizes voice/video traffic

📦 Data Unit: Packets

Contains IP addresses for routing across networks

7 / 18

Layer 2 - Data Link

🔗 Physical Addressing

Provides node-to-node transfer and error detection. Uses frames.

Key Functions:

  • Framing: Divides data into manageable frames
  • MAC Addressing: Uses physical addresses to identify devices
  • Error Detection: Uses CRC, checksums for data integrity
  • Flow Control: Prevents fast senders overwhelming slow receivers
  • Switching: Forwards frames using MAC addresses

📦 Data Unit: Frames

MAC addresses + error checking + packets

🔧 Devices

Switches, Bridges, NICs

Data Encapsulation

📦 How Data Moves Through Layers

As data moves down the OSI model, each layer adds its own header information

Layers 7-5: Data - Application data

Layer 4: Segments - TCP/UDP headers + data

Layer 3: Packets - IP headers + segments

Layer 2: Frames - MAC headers + packets

Layer 1: Bits - Raw binary (1s and 0s)

11 / 19

Segments, Packets & Frames

📦 Segment (Layer 4)

Content: TCP/UDP headers with port numbers + application data

Purpose: Ensures reliable, ordered data transfer with flow control

📮 Packet (Layer 3)

Content: IP headers with addresses + segments

Purpose: Routing across different networks

Routing: Based on destination IP address

🖼️ Frame (Layer 2)

Content: MAC addresses + error checking (CRC) + packets

Purpose: Prepares for transmission over physical medium (Ethernet, Wi-Fi)

Error Checking: Detects and corrects transmission errors

OSI vs TCP/IP Models

Two Conceptual Frameworks

OSI is theoretical (7 layers), TCP/IP is practical implementation (4 layers)

OSI Model

7 - Application
6 - Presentation
5 - Session
4 - Transport
3 - Network
2 - Data Link
1 - Physical

TCP/IP Model

4 - Application
(OSI 7, 6, 5)
3 - Transport
2 - Internet
1 - Network Interface
(OSI 2, 1)
13 / 19

TCP/IP Model Details

Layer 4 - Application

Applications, compression, encryption, protocols (SMTP, POP, HTTP, DNS, FTP)

Layer 3 - Transport

Reliable data transfer using TCP or UDP. Breaks data into packets.

Layer 2 - Internet

Finds shortest/quickest route to destination. IP protocol assigns origin and destination addresses.

Layer 1 - Network Interface

Decides which device's turn to communicate. Locates physical device on network.
