# 2 
One advantage of using HTTPS is that it is more secure than HTTP as it encrypts the data being transmitted between the client and the server. This ensures that the data is not intercepted or tampered with during transmission.
Another advantage of HTTPS is that it provides authentication, ensuring that the client is communicating with the intended server and not a malicious entity.
Another advantage of HTTPS is that it provides integrity, ensuring that the data received by the client has not been altered during transmission.

DNS is used so that we do not have to remember IP addresses. Instead we use a domain name which is easier to remember and type. This allows us to access websites and services using a memorable name rather than a long and complex IP address.
