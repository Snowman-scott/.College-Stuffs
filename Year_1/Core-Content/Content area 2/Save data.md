Computers save Data to “files” that are stored on your secondary storage (a HDD or An SSD) Secondary storage is non-volatile which means data is not lost when power is lost unlike RAM where the data is lost when the power is removed because it is a Volatile memory 

You want to store Files when the computer is off to keep configuration files, save data for website caches, game saves, user data, user accounts ETC….

These save files are usually small KB to MB depending on the complexity of the file

Types of files for these purposes are:
-	.sav
-	.save
-	.dat
-	.bin
-	.json
-	.xml
-	.cfg
-	.slot
-	.tmp
Game Specific save files are:
-	.ess
-	.gvas
-	.mcr
-	.srm
-	.state
