# Exam Question
## An unsorted dataset has 100,000 items in it. Evaluate the use of searching and sorting algorithm that could be used to find an item in this dataset. (9)

We could use a linear search or a binary search. If the dataset is sorted, a binary search would be more efficient. If the dataset is not sorted, a linear search would be more appropriate. However we could use a bubble sort, merge sort or an insertion sort. If the dataset is very large we could sort it using a merge or insertion sort. these would be the quickest sorting algorithms. After sorting the dataset we could use a binary search to find the item.  
A bubble sort works by repeatedly swapping adjacent elements until the entire dataset is sorted. It goes through multiple passes, comparing each element to its adjacent element and swapping them if they are in the wrong order. This process continues until no more swaps are needed, indicating that the dataset is sorted. The time complexity of bubble sort is O(n^2), where n is the number of elements in the dataset.  
A merge sort works by dividing the dataset into smaller subarrays, sorting each subarray recursively, and then merging the sorted subarrays back together. This process continues until the entire dataset is sorted. The time complexity of merge sort is O(n log n), where n is the number of elements in the dataset.  
An insertion sort works by iterating through the dataset, inserting each element into its correct position in a sorted subarray. This process continues until the entire dataset is sorted. The time complexity of insertion sort is O(n^2), where n is the number of elements in the dataset.  
A linear search works by iterating through the dataset one item at a time, comparing each item to the target value until a match is found or the end of the dataset is reached. This is slow and inefficient for large datasets. A binary search works by repeatedly dividing the dataset in half until the target value is found or the search space is empty. This is much faster than a linear search for large datasets.  
For this specific scenario, I would use a merge sort because it's time and complexity are both 0(n log n), which is more efficient than a bubble or insertion sort. I would then use a binary search to find the item that is being searched for. this is more efficient than a linear search for this large dataset.
