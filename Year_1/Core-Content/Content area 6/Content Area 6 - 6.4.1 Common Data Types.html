Understanding Data Types

Why Do Data Types Matter?

Data types define how data is stored in memory, what operations can be performed on it, and how much space it requires. Choosing the correct data type ensures efficient storage, accurate processing, and prevents errors.

Memory Efficiency

Different data types use different amounts of memory. An integer uses 4 bytes, whilst a string can use hundreds.

Valid Operations

You can add integers (5 + 3 = 8) but can't add Booleans (True + False = error).

Data Validation

Data types enforce rules. Age (integer) can't accidentally store "twenty-five".

Database Design

Proper data types enable indexing, sorting, and efficient querying in databases.

Integer Data Type

DEFINITION

What is an Integer?

An integer is a whole number data type that can be positive, negative, or zero. Integers do not have decimal points or fractional parts.

Key Characteristics

🔢 Whole Numbers Only

No decimal points. Examples: -100, -1, 0, 1, 42, 1000, 999999

💾 Fixed Memory Size

Typically 4 bytes (32-bit) or 8 bytes (64-bit). Determines the range of values.

➕ Mathematical Operations

Supports addition, subtraction, multiplication, division (results in integer).

📊 Range Limits

32-bit: -2,147,483,648 to 2,147,483,647. 64-bit: much larger range.

Common Uses:

  • Counting items (5 students)
  • Age in years (25)
  • Quantity in stock (147)
  • User IDs (123456)
  • Page numbers (1, 2, 3...)
  • Days in month (30)
  • Score (0-100)
  • Year (2026)
  • Temperature in °C (-5)
Examples: age = 25 | quantity = 100 | temperature = -5 | userID = 789012

Real Data Type

DEFINITION

What is a Real Number?

A real number (also called floating-point or float) is a numeric data type that can represent numbers with decimal points and fractional values. It allows for precise measurements.

Key Characteristics

📏 Decimal Precision

Can store fractional values: 3.14159, 0.5, -12.75, 98.6

💾 Larger Memory

32-bit (float): ~7 decimal digits. 64-bit (double): ~15 decimal digits precision.

🔬 Scientific Notation

Can represent very large (1.5e10) or very small (3.2e-8) numbers.

⚠️ Rounding Issues

Finite precision can cause rounding errors (0.1 + 0.2 ≠ exactly 0.3).

Common Uses:

  • Prices (£19.99, £45.50)
  • Measurements (1.75m)
  • Weight (68.4kg)
  • Temperature (36.7°C)
  • Percentages (87.5%)
  • Coordinates (51.5074, -0.1278)
  • Interest rates (3.25%)
  • Speed (65.4 mph)
  • Scientific data (9.81 m/s²)
Examples: price = 19.99 | height = 1.75 | temperature = 36.8 | pi = 3.14159

Character Data Type

DEFINITION

What is a Character?

A character (char) is a data type that stores a single character, letter, digit, or symbol. It represents one unit of text.

Key Characteristics

1️⃣ Single Character Only

Stores exactly one character: 'A', 'z', '5', '@', '!', ' ' (space)

💾 Small Memory Footprint

Typically 1 byte (ASCII) or 2 bytes (Unicode). Very memory efficient.

🔤 Written in Quotes

Single quotes in code: 'A', 'b', '9', '$'. Distinguishes from strings.

🔢 ASCII/Unicode Values

Each character has a numeric code: 'A' = 65, 'a' = 97, '0' = 48

Common Uses:

  • Single initials ('J', 'K')
  • Grade letters ('A', 'B', 'C')
  • Yes/No indicators ('Y', 'N')
  • Gender codes ('M', 'F')
  • Menu choices ('1', '2', '3')
  • Special symbols ('@', '#', '$')
  • Status codes ('A', 'P', 'C')
  • Currency symbols ('£', '$', '€')
  • Punctuation marks ('.', ',', '!')
Examples: initial = 'J' | grade = 'A' | gender = 'M' | symbol = '@'

String Data Type

DEFINITION

What is a String?

A string is a data type that stores a sequence of characters. It can contain letters, numbers, spaces, and symbols in any combination and length.

Key Characteristics

📝 Multiple Characters

Can be any length: "", "A", "Hello", "The quick brown fox jumps..."

💾 Variable Memory

Memory usage depends on length. Each character typically uses 1-2 bytes.

"" Double Quotes

Written in double quotes: "Hello World", "123 Main St", "user@email.com"

🔗 Concatenation

Can join strings: "Hello" + " " + "World" = "Hello World"

Common Uses:

  • Names ("Sarah Johnson")
  • Addresses ("123 Main St")
  • Email ("user@email.com")
  • Descriptions ("Product info")
  • Messages ("Welcome back!")
  • Passwords ("P@ssw0rd!")
  • URLs ("www.example.com")
  • Product codes ("SKU-12345")
  • Sentences (any text)
Examples: name = "Sarah Johnson" | email = "sarah@example.com" | message = "Hello!"

Boolean Data Type

DEFINITION

What is a Boolean?

A Boolean is a logical data type that can only have two possible values: True or False. It represents yes/no, on/off, 1/0 conditions.

Key Characteristics

✓ / ✗ Two Values Only

True or False. No other values possible. Binary choice.

💾 Minimal Memory

Typically 1 bit (0 or 1), though often stored as 1 byte for efficiency.

🔀 Logical Operations

AND, OR, NOT operations. Example: True AND False = False

❓ Conditional Logic

Used in if statements: if (isLoggedIn == True) { ... }

Common Uses:

  • User logged in? (True/False)
  • Email verified? (True/False)
  • Account active? (True/False)
  • Task completed? (True/False)
  • Payment successful? (True/False)
  • Age >= 18? (True/False)
  • In stock? (True/False)
  • Dark mode enabled? (True/False)
  • Notifications on? (True/False)
Examples: isLoggedIn = True | emailVerified = False | isDarkMode = True

Date Data Type

DEFINITION

What is a Date?

A date (or datetime) data type stores dates and times in a standardised format. It can represent a specific point in time with date, time, or both combined.

Key Characteristics

📅 Standardised Format

Common formats: DD/MM/YYYY, YYYY-MM-DD, MM/DD/YYYY. Varies by region/system.

⏰ Time Components

Can include time: 14:30:00, or full datetime: 2026-01-15 14:30:00

🔢 Stored as Number

Internally stored as number (seconds/days since reference date) for calculations.

➕ Date Arithmetic

Can add/subtract dates: "15/01/2026" + 7 days = "22/01/2026"

Common Uses:

  • Birthdays (15/03/1998)
  • Order dates (15/01/2026)
  • Due dates (31/12/2026)
  • Appointment times (14:30:00)
  • Event timestamps (2026-01-15 14:30)
  • Expiry dates (30/06/2027)
  • Last login (15/01/2026 09:45)
  • Created date (01/01/2025)
  • Modified date (15/01/2026)
Examples: birthday = 15/03/1998 | orderDate = 2026-01-15 | appointmentTime = 14:30:00

Blob Data Type

DEFINITION

What is a Blob?

A Blob (Binary Large Object) is a data type that stores large amounts of binary data such as images, audio, video, or any file in its raw binary format.

Key Characteristics

💾 Binary Storage

Stores data as 1s and 0s. Not human-readable like text or numbers.

📦 Large Size

Can store MB or GB of data. Images: 2-10MB, Videos: 100s of MB to GBs.

🎯 File Types

Images (JPG, PNG), Audio (MP3, WAV), Video (MP4, AVI), Documents (PDF).

🔍 No Direct Querying

Cannot search inside Blob like text. Must retrieve entire object.

Common Uses:

  • Profile pictures (JPG, PNG)
  • Product images
  • Scanned documents (PDF)
  • Audio files (MP3, WAV)
  • Video content (MP4)
  • Podcast recordings
  • Medical images (X-rays, MRI)
  • Backup files
  • Encrypted data
Examples: profilePicture = [binary image data] | videoFile = [binary video data]

Choosing the Right Data Type

Decision Guide

Selecting the appropriate data type is crucial for efficient data storage and processing.

Use Integer When...

  • Counting discrete items (students, products)
  • Age in years (no need for decimal precision)
  • IDs and reference numbers
  • Quantities that are whole numbers
  • Mathematical calculations don't need decimals

Use Real When...

  • Measuring continuous values (height, weight)
  • Financial calculations (£19.99)
  • Scientific measurements (36.8°C)
  • Percentages with precision (87.5%)
  • Any value requiring decimal points

Use Character When...

  • Storing single letters or initials ('J')
  • Grade letters ('A', 'B', 'C')
  • Yes/No flags ('Y', 'N')
  • Single-digit codes or symbols
  • Memory efficiency critical (vs string)

Use String When...

  • Storing names, addresses, descriptions
  • Email addresses, URLs, messages
  • Any text longer than one character
  • Product codes, postcodes
  • Human-readable identifiers

Use Boolean When...

  • Two possible states (on/off, yes/no)
  • Flags for settings (dark mode on?)
  • Status indicators (completed?)
  • Permission checks (is admin?)
  • Conditional logic requirements

Use Date When...

  • Recording birthdays, events
  • Tracking timestamps (created, modified)
  • Scheduling appointments
  • Expiry dates, due dates
  • Need date calculations (age, duration)

Use Blob When...

  • Storing images (JPG, PNG, GIF)
  • Storing audio files (MP3, WAV)
  • Storing video content (MP4, AVI)
  • Storing PDF documents
  • Storing any binary file format
  • Large file uploads to database

Real-World Example: E-Commerce Database

Product Database Design

How different data types work together in a practical system:

Products Table

ProductID (Integer) 1001, 1002, 1003
ProductName (String) "Wireless Mouse", "USB Cable"
Price (Real) £19.99, £8.50, £45.75
StockQuantity (Integer) 47, 123, 5
InStock (Boolean) True, True, False
Category (Character) 'E' (Electronics), 'C' (Cables)
DateAdded (Date) 15/01/2026, 12/01/2026
ProductImage (Blob) [Binary image data]

Why These Types?

ProductID (Integer): Unique identifier, whole numbers only, no decimals needed

ProductName (String): Variable length text, can include spaces and special characters

Price (Real): Money values with decimal precision (£19.99)

StockQuantity (Integer): Count of items, can't have 47.5 products

InStock (Boolean): Simple yes/no, available or not, True/False

Category (Character): Single letter code for efficiency, saves memory

DateAdded (Date): Track when product added, enable date sorting/filtering

ProductImage (Blob): Store actual image file in database as binary

Summary & Exam Tips

Key Points - Content Area 6.4.1

Integer: Whole numbers only (no decimals). Used for counting, IDs, ages. Example: 42, -5, 1000. Memory: 4 bytes.

Real (Float): Decimal numbers for measurements. Used for prices, heights, temperatures. Example: 19.99, 1.75, 36.8. Memory: 4-8 bytes.

Character: Single character only. Used for initials, grades, codes. Example: 'A', 'z', '5', '@'. Memory: 1-2 bytes.

String: Multiple characters (text). Used for names, emails, addresses. Example: "Sarah Johnson", "user@email.com". Memory: Variable.

Boolean: True or False only. Used for yes/no, on/off flags. Example: True, False. Memory: 1 bit (1 byte stored).

Date/DateTime: Dates and times in standard format. Used for birthdays, appointments, timestamps. Example: 15/01/2026, 14:30:00. Memory: 4-8 bytes.

Blob: Binary Large Object for files. Used for images, audio, video, PDFs. Example: [image data], [video data]. Memory: MBs to GBs.

Exam Success Tips

1. Decimal Point Test

Needs decimals? → Real. Whole numbers only? → Integer. Simple check for numeric types.

2. Text Length Check

One character? → Character. Multiple characters? → String. Don't confuse these!

3. True/False Scenarios

Two states only (yes/no, on/off)? → Boolean. More options? → Use categorical codes instead.

4. Date vs String

Need date calculations? → Date type. Just displaying? → Could use String (but Date preferred).

5. File Storage = Blob

Any file (image, video, PDF, audio)? → Blob. This is the only type for binary files.

6. Memory Efficiency

Explain tradeoffs: Character (1 byte) vs String (variable). Integer vs Real precision.

7. Real-World Context

Use examples: "Price needs Real because £19.99 has decimal places for pence."

8. Wrong Type Consequences

In evaluation questions, explain what breaks: Integer for price loses pence (£19.99 → £19).
