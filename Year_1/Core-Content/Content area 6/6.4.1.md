## Question 6 (12 marks)

A hospital is designing a new patient management system that needs to store comprehensive patient information efficiently and securely.

**Context:**

**Patient Demographics:**
- NHS Number: 9 digits (e.g., 123456789)
- Full Name: First name and surname
- Date of Birth: e.g., 15/03/1985
- Blood Group: Single letter with modifier (e.g., A, B, O, AB)
- Organ Donor: Yes or No

**Medical Measurements:**
- Height: Measured in metres (e.g., 1.75m, 1.82m)
- Weight: Measured in kilograms (e.g., 68.4kg, 72.1kg)
- Body Temperature: e.g., 36.8°C, 37.2°C, 38.5°C
- Heart Rate: Beats per minute (e.g., 72, 85, 68)
- Number of Dependants: e.g., 0, 1, 2, 3

**Medical Records:**
- Last Appointment Date: e.g., 10/01/2026
- Next Appointment: Date and time (e.g., 20/01/2026 14:30)
- Currently Admitted: Whether patient is in hospital or not
- X-ray Images: Chest X-rays, bone scans (stored as image files)
- MRI Scans: Brain and body scans (stored as image files)
- Medical History PDF: Scanned historical documents

The database designer must select appropriate data types that balance storage efficiency, data integrity, and system performance.

**Evaluate** the most appropriate data type for each category of information (Demographics, Measurements, Records).

**Justify** why Blob is the most appropriate data type for storing X-ray images, MRI scans, and medical history PDFs.

**Explain** the potential consequences of choosing incorrect data types for medical measurements like body temperature or heart rate.

*Your answer should demonstrate understanding of: data type characteristics, memory efficiency, precision requirements, and the importance of data integrity in medical systems. Consider what would happen if Integer was used instead of Real for temperature, or String instead of Boolean for admission status.*
