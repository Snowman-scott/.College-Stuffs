# Task 2 T_T

## Testing types

### System test
Testing the entire code

### Unit test
Testing a specific Function

### Erroneous test
Testing the code can handle errors

### Boundary test
Testing the range of accepted values

### regression test 
Testing bug fixes have not caused further problems within the code

### Stress testing 
Testing to see how the application runs and if it fails at lower RAM builds. Multi system testing and testing to see how it runs with background applications running.

### Acceptance and Usability testing 
Testing that the system works in a practical environment
