# Colour pallet

## Light Mode

Neutrals (shared)

#FDF9F4 — bg (warm white)
#F5EDE2 — surface/card
#E3D5C2 — border/divider
#2B2118 — text primary → 15:1 on bg (AAA)
#6B5847 — text secondary/muted → 6.4:1 on bg (AA)

Accents — one per subsystem, same weight so neither dominates

#7A4A2E — Kennel brown (pastebin side) → 7.4:1 with white text (AAA, safe for buttons)
#2E6E8E — Zoomies blue (shortener side) → 5.6:1 with white text (AA)

Semantic (shared)

#3F7D4F — success → 4.9:1 with white text (AA)
#B23A3A — error → 5.9:1 with white text (AA)
#E0A93E — warning → 7.4:1 with dark text (#2B2118), don't pair with white text, it fails
